# EduOS Parent 使用指南

**版本**: V1.1  
**更新日期**: 2026-07-28  
**目标用户**: 家长

---

## 1. 系统概述

EduOS 家长端为家长提供查看孩子学习情况、考勤记录、课程进度等功能。

### 1.1 核心功能
- ✅ 查看我的孩子
- ✅ 查看孩子课程
- ✅ 查看孩子考勤
- ✅ 查看孩子合同
- ✅ 提交请假申请
- ✅ 查看课程反馈

### 1.2 权限说明
- 仅能访问自己关联的孩子数据
- 不能访问其他家长的数据
- 不能修改系统设置

## 2. 登录与认证

### 2.1 登录流程
```
1. 访问登录页面
2. 输入用户名和密码
3. 点击登录按钮
4. 系统验证 credentials
5. 返回 JWT Token
6. 跳转到家长首页
```

### 2.2 Token 管理
- **Token 有效期**: 2 小时
- **Refresh Token**: 7 天
- **自动刷新**: 支持

### 2.3 安全建议
- ✅ 使用强密码
- ✅ 定期更换密码
- ✅ 不在公共网络登录
- ✅ 及时退出登录

## 3. 我的孩子

### 3.1 查看孩子列表
```

API: GET /api/v1/students/my-children

展示内容:
```

## 7. 请假申请

### 7.1 提交请假
```
路径: 请假申请 > 提交请假

操作步骤:
1. 选择孩子
2. 选择请假日期
3. 选择请假类型
   - 病假
   - 事假
   - 其他
4. 填写请假原因
5. 提交申请
```

### 7.2 请假记录
```
路径: 请假申请 > 请假记录

查看内容:
- 请假历史
- 审批状态
  - PENDING: 待审批
  - APPROVED: 已批准
  - REJECTED: 已拒绝
- 审批意见
```

### 7.3 请假统计
```
路径: 请假申请 > 请假统计

统计指标:
- 请假次数
- 请假类型分布
- 请假天数
- 审批通过率
```

## 10. 常见问题

### 10.1 登录问题
**Q: 忘记密码怎么办？**  
A: 联系系统管理员重置密码。

**Q: Token 过期了怎么办？**  
A: 系统会自动刷新 Token，如果仍然失败，请重新登录。

### 10.2 权限问题
**Q: 为什么看不到孩子的数据？**  
A: 请确认您已正确关联孩子，如果仍然看不到，请联系管理员。

**Q: 为什么不能修改某些数据？**  
A: 某些数据需要管理员权限，请联系管理员。

### 10.3 考勤问题
**Q: 考勤记录错误怎么办？**  
A: 联系教师或管理员更正考勤记录。

**Q: 请假申请被拒绝了怎么办？**  
A: 查看拒绝原因，如果认为不合理，可以联系教师或管理员。

### 10.4 合同问题
**Q: 课时数不对怎么办？**  
A: 联系管理员核实课时数。

**Q: 合同快到期了怎么办？**  
A: 联系管理员续费或续签合同。
