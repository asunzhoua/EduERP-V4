# EduOS Teacher 使用指南

**版本**: V1.1  
**更新日期**: 2026-07-28  
**目标用户**: 教师

---

## 1. 系统概述

EduOS 教师端为教师提供课程管理、班级管理、学生管理、考勤管理等功能。

### 1.1 核心功能
- ✅ 查看我的课程
- ✅ 查看我的班级
- ✅ 查看我的学生
- ✅ 考勤管理
- ✅ 课程反馈
- ✅ 请假申请

### 1.2 权限说明
- 仅能访问自己负责的课程、班级和学生
- 不能访问其他教师的数据
- 不能修改系统设置

## 2. 登录与认证

### 2.1 登录流程
```
1. 访问登录页面
2. 输入用户名和密码
3. 点击登录按钮
4. 系统验证 credentials
5. 返回 JWT Token
6. 跳转到教师首页
```

### 2.2 Token 管理
- **Token 有效期**: 2 小时
- **Refresh Token**: 7 天
- **自动刷新**: 支持

### 2.3 安全建议
- ✅ 使用强密码
- ✅ 定期更换密码
- ✅ 不在公共网络登录
- ✅ 及时退出登录

## 3. 我的课程

### 3.1 查看课程列表
```
路径: 我的课程

API: GET /api/v1/teachers/me/courses

展示内容:
- 课程编号
- 课程名称
- 科目
- 年级
- 总课时数
```

### 3.2 课程详情

## 6. 考勤管理

### 6.1 课堂签到
```
路径: 考勤管理 > 课堂签到

操作步骤:
1. 选择班级
2. 选择日期
3. 标记学生出勤状态
   - PRESENT: 出勤
   - LATE: 迟到
   - LEAVE: 请假
   - ABSENT: 缺勤
4. 提交签到记录
```

### 6.2 考勤记录

## 10. 常见问题

### 10.1 登录问题
**Q: 忘记密码怎么办？**  
A: 联系系统管理员重置密码。

**Q: Token 过期了怎么办？**  
A: 系统会自动刷新 Token，如果仍然失败，请重新登录。

### 10.2 权限问题
**Q: 为什么看不到某些数据？**  
A: 您只能访问自己负责的课程、班级和学生数据。

**Q: 为什么不能修改某些数据？**  
A: 某些数据需要管理员权限，请联系管理员。

### 10.3 考勤问题
**Q: 签到失败了怎么办？**  
A: 检查网络连接，如果仍然失败，请联系技术支持。

**Q: 考勤记录错误怎么办？**  
A: 联系管理员更正考勤记录。
