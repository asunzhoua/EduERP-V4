## 1. 系统概述

EduOS 是一个教育管理系统，提供学生管理、课程管理、班级管理、教师管理、考勤管理、薪酬管理等功能。

### 1.1 核心功能
- ✅ 学生管理
- ✅ 课程管理
- ✅ 班级管理
- ✅ 教师管理
- ✅ 考勤管理
- ✅ 薪酬管理
- ✅ 数据导出
- ✅ 经营概览

### 1.2 系统架构
- **后端**: NestJS + TypeScript
- **数据库**: MySQL 8.0
- **认证**: JWT
- **监控**: Sentry APM
- **性能**: 平均响应时间 245ms

## 2. 登录与认证

### 2.1 登录流程
```
1. 访问登录页面
2. 输入用户名和密码
3. 点击登录按钮
4. 系统验证 credentials
5. 返回 JWT Token
6. 跳转到首页
```

### 2.2 Token 管理
- **Token 有效期**: 2 小时
- **Refresh Token**: 7 天
- **自动刷新**: 支持

### 2.3 安全建议
- ✅ 使用强密码（至少 12 位）
- ✅ 定期更换密码
- ✅ 不在公共网络登录
- ✅ 启用双因素认证（如可用）

## 3. 学生管理

### 3.1 创建学生
```
路径: 学生管理 > 创建学生

必填字段:
- 学生姓名
- 性别
- 出生日期
- 学校
- 年级

可选字段:
- 联系电话
- 邮箱
- 标签
- 备注
```

### 3.2 查询学生
```
路径: 学生管理 > 学生列表

支持筛选:
- 按学校
- 按年级
- 按状态
- 按标签

支持搜索:
- 按学生姓名
- 按学号
- 按联系电话
```

### 3.3 编辑学生
```
路径: 学生管理 > 学生列表 > 编辑

可修改字段:
- 基本信息
- 联系方式
- 标签
- 状态
```

### 3.4 删除学生
```
路径: 学生管理 > 学生列表 > 删除

注意事项:
- 删除前确认
- 关联数据会保留
- 软删除机制
```

## 12. 常见问题

### 12.1 登录问题
**Q: 忘记密码怎么办？**  
A: 联系系统管理员重置密码。

**Q: Token 过期了怎么办？**  
A: 系统会自动刷新 Token，如果仍然失败，请重新登录。

### 12.2 数据问题
**Q: 数据导出失败怎么办？**  
A: 检查网络连接，如果仍然失败，请联系技术支持。

**Q: 数据统计不准确怎么办？**  
A: 检查数据源，如果仍然不准确，请联系技术支持。

### 12.3 性能问题
**Q: 系统响应慢怎么办？**  
A: 检查网络连接，如果仍然慢，请联系技术支持。

**Q: 页面加载失败怎么办？**  
A: 刷新页面，如果仍然失败，请联系技术支持。
